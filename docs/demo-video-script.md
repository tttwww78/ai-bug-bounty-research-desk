# ScopeDesk Demo Video Script

**Target length:** 75–90 seconds, under the Kiroween three-minute limit.
**Language:** English narration or captions.
**Data:** Use only the built-in fictional `example.test` sample.

| Time | On-screen action | Narration / caption |
| --- | --- | --- |
| 0:00–0:08 | Title screen: ScopeDesk — Policy Change Review | Program rules change. Review the exact text before changing your testing plan. |
| 0:08–0:20 | Show the two rule text panels and the Local only badge | Paste the previous and current policy text. The demo processes it in your browser and does not fetch target pages. |
| 0:20–0:36 | Load the fictional sample and click Compare versions | ScopeDesk shows unchanged lines alongside additions and removals. Unchanged entries identify the previous and current source line separately. |
| 0:36–0:48 | Demonstrate the Unchanged filter button and summary count | Filter between All, Added, Removed, and Unchanged. The summary grid shows the unchanged count separately. |
| 0:48–1:00 | Show candidate domains, paths, and rate-limit text | Pattern matches are candidates only. The original wording remains visible so a researcher can review it. |
| 1:00–1:15 | Mark changes reviewed and export Markdown | Mark added/removed changes reviewed (unchanged lines do not have review checkboxes). Export creates a local Markdown record with a separate unchanged section. |
| 1:15–1:27 | End card with the safety boundary | ScopeDesk does not scan, exploit, or submit targets. Authorization and verification stay with the researcher. |

## Capture notes

- Show the real published app at desktop width and keep the browser address bar visible briefly.
- Use no personal data, real program rules, API keys, copyrighted music, or third-party logos.
- Keep the final video public on YouTube and below three minutes, as required by the official rules.
